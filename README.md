# 🏦 Bankist Application

A modern banking application built with JavaScript that allows users to manage accounts, transfer money, request loans, and track transaction history through a clean and intuitive interface.

Bankist simulates core online banking features while demonstrating modern JavaScript concepts, application architecture, and user-focused design principles.

## 🚀 Live Demo

**Try it here:** bankist-application-desktop-only.vercel.app 

**Try using a VPN if you are in Iran**

## ✨ Features

* 🔐 User authentication system
* 💸 Transfer money between accounts
* 💰 Request loans
* 🧾 View transaction history
* 📊 Account balance tracking
* ⏱️ Automatic logout timer
* 🔄 Sort transaction movements
* 📱 Responsive and user-friendly interface
* ⚡ Fast and interactive user experience
